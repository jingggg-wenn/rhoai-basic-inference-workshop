[#introduction]
= Introduction

This workshop is a hands-on guide for deploying and testing AI model inference on OpenShift AI 3.5. You will deploy a model from the model catalog, configure Model-as-a-Service (MaaS) with tiered access, set up a chat interface, and test end-to-end inference.

[TIP]
====
For a scripted environment setup (MaaS gateway, operators, dashboard features, DevSpaces, and more), see the https://github.com/jingggg-wenn/rhoai-sno-setup-guide[RHOAI 3.5 SNO Setup Guide]. It automates the full cluster preparation in two scripts.
====

== What You Will Learn

By the end of this workshop, you will be able to:

* Create a Data Science project in {productname-short}
* Deploy an AI model from the model catalog using the llm-d serving runtime
* Configure MaaS subscriptions with different token rate limits (premium and basic tiers)
* Generate API keys for authenticated model access
* Deploy Open WebUI as a self-hosted chat interface
* Connect Open WebUI to your model via the MaaS gateway and test chat-based inference

== Prerequisites

Before starting, confirm the following are ready:

* A running {ocp} cluster with {rhoai-short} {rhoai-version} installed
* At least one GPU node available in the cluster (for example, NVIDIA L4, L40S, or A100)
* A GPU hardware profile created by your administrator
* Your login credentials (username and password provided by your instructor)

== Your User Account 

Throughout this guide, you will see `user-XX` or `admin-XX`. Replace `XX` with your assigned number.

For example, if you are *user 5*, then:

* `user-XX` becomes `user-05`
* Your project name is `user-05`

Always use two digits: user05 = `user-05`, admin02 = `admin-02`.
