== 단계 5.1: Playground 실행

좌측 사이드바에서 *Gen AI Studio* > *AI asset endpoints*로 이동합니다. 배포된 모델이 *Ready* 상태로 표시되어야 합니다. *Try in playground*를 클릭하여 Playground 환경을 실행합니다.

image::ai-playground/img-try-in-playground.png[모델이 Ready 상태로 표시되고 Try in playground 버튼이 있는 AI asset endpoints 페이지]

NOTE: Playground 환경은 처음 접근 시 프로비저닝에 수 분이 소요될 수 있습니다. 로딩이 완료될 때까지 기다린 후 프롬프트를 전송하십시오.

Playground가 로드되면 우측 설정 패널에 *Model*, *Subscription*, *Temperature*, *Streaming* 컨트롤이 표시됩니다.

image::ai-playground/img-playground-launched.png[모델, 구독 선택기, 온도, 스트리밍 설정이 표시된 Playground 인터페이스]

== 단계 5.2: 다른 구독 등급으로 채팅 비교

상단 툴바에서 *Compare chat*을 클릭하여 나란히 비교 보기를 엽니다. 이를 통해 동일한 프롬프트를 두 개의 채팅 세션에 동시에 전송하여 서로 다른 MaaS 구독 등급을 테스트할 수 있습니다.

=== Chat 1 구성 -- Premium

. 우측 상단 설정 패널에서 *Chat 1* 탭을 클릭합니다.
. *Subscription*에서 드롭다운을 열고 `workshop-gemma4-premium`을 선택합니다.
. 모델, 온도, 스트리밍 설정은 기본값으로 유지합니다.

image::ai-playground/img-chat1-premium.png[workshop-gemma4-premium 구독이 설정된 Chat 1]

=== Chat 2 구성 -- Basic

. 설정 패널에서 *Chat 2* 탭을 클릭합니다.
. *Subscription*에서 드롭다운을 열고 `workshop-gemma4-basic`을 선택합니다.
. 기타 모든 설정은 Chat 1과 동일하게 유지합니다.

image::ai-playground/img-chat2-basic.png[workshop-gemma4-basic 구독이 설정된 Chat 2]

=== 프롬프트 전송 및 비교

하단의 공유 메시지 입력란에 프롬프트를 입력하고 (예: `Explain how binary search works and write a Python implementation with comments.`) Enter를 누릅니다. 프롬프트가 두 채팅에 동시에 전송됩니다.

처음 몇 개의 프롬프트에서는 양쪽 모두 동일한 응답이 반환됩니다 -- 동일한 모델이 두 채팅을 모두 처리하고 있기 때문입니다. 그러나 프롬프트를 계속 전송하면 *Chat 2 (Basic)*는 토큰 속도 제한에 도달하여 *Server error*를 반환하는 반면, *Chat 1 (Premium)*은 중단 없이 응답을 계속합니다.

image::ai-playground/img-compare-chats-ratelimited.png[Chat 1 Premium은 정상 응답하고 Chat 2 Basic은 속도 제한으로 Server error가 발생한 비교 채팅]

이것이 MaaS 구독 등급 시스템의 동작입니다:

* *Chat 1 (Premium)* -- `workshop-gemma4-premium`은 `10,000` 토큰/분의 속도 제한이 있어 스로틀링 없이 지속적인 대화를 처리합니다.
* *Chat 2 (Basic)* -- `workshop-gemma4-basic`은 `100` 토큰/분의 속도 제한이 있어 몇 차례의 대화 후 속도가 제한되고 오류가 반환됩니다.

두 채팅 모두 동일한 모델과 동일한 인프라를 사용합니다. 유일한 차이점은 각 채팅 세션에 할당된 구독 등급입니다. 이것이 MaaS를 통해 관리자가 차등화된 서비스 수준을 제공하는 방식입니다 -- Premium 사용자는 높은 처리량을 확보하고 일반 사용자는 더 엄격한 할당량이 적용되며, 모델 배포 자체에는 어떠한 변경도 필요하지 않습니다.

== 추가 탐색: Playground 설정

Model 및 Subscription 탭 외에도 Playground 설정 패널은 다음과 같은 추가 기능을 제공합니다:

image::ai-playground/img-playground-explore-settings.png[Model, Prompt, Knowledge, MCP, Guardrails 탭이 표시된 Playground 설정 패널]

* *Prompt* -- 시스템 프롬프트를 정의하여 모델의 동작을 제어합니다 (예: "You are a helpful coding assistant" 또는 "한국어로만 응답하세요").
* *Knowledge* -- 문서(PDF, 텍스트)를 업로드하여 검색 증강 생성(RAG)을 활성화합니다. Playground가 업로드된 콘텐츠를 컨텍스트로 사용하여 질문에 답변합니다.
* *MCP* -- MCP (Model Context Protocol) 서버에 연결하여 외부 도구 및 데이터 소스로 모델을 확장합니다.
* *Guardrails* -- 콘텐츠 안전 필터를 활성화하여 유해한 입력 또는 출력을 감지하고 차단합니다 (예: PII 감지, 프롬프트 인젝션, 유해성 검사).

이 기능들은 본 워크숍의 범위를 벗어나지만 자율 학습을 위해 제공됩니다.
