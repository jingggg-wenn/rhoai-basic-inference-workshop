= Basic Inferencing on Red Hat AI

A hands-on workshop for deploying and testing AI model inference on {rhoai} {rhoai-version}.

Participants learn to create a data science project, deploy a model from the model catalog using the vLLM runtime, connect it to Open WebUI, and test chat and RAG capabilities.

Created: 2026-10-05

=== Local Development

==== Using Containers (Recommended)

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----

For SELinux environments:

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora:z -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----

Open http://localhost:8080 in your browser.
